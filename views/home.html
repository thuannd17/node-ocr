Roster OCR

Reads crew rosters (eCrew screenshots, duty-plan PDFs, CSV / Excel exports) into Published / Planned rows with a self-learning AI model, and turns them into calendars, airport details and night time.

Tools

Open to everyone, also as a public API for other apps.

Upload Roster

Upload roster images, PDFs, CSV or Excel files (drop or pick) and see the Published / Planned rows the AI model reads, then export them to a calendar.

/upload AI Model

Calendar

Open .ics files as a month or list calendar: duties from check-in to check-out with their flights, sims and hotels.

/calendar

Airport

Find an airport by IATA, ICAO, FAA or WMO code or by name: codes, coordinates, map and 7-day weather.

/airport

Night Time

Night time of a flight along the great circle, from the sun's altitude at the aircraft, with the route on a map.

/night-time

API Docs

The public API for other apps: read rosters, export .ics, airports and weather, night time (OpenAPI).

/api-docs OpenAPI

Administration

Managing the data and the models. These pages will need an account with the right permissions; for now they are only kept apart.

Label Tool

Label (ground truth) every image in fake-data/, with Auto-fill from OCR to fix by hand.

/label Data

Benchmark

Accuracy of every cell (date, duty, dep, begin, end, arr…) against the labels in labels/.

/benchmark Measure

AI Models

The model versions that read rosters: train new ones, compare their scores, activate or delete them.
