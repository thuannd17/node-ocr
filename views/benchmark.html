Benchmark Accuracy

Chấm điểm trên các file đã gán nhãn (labels/<đuôi>/): (1) OCR nhận dạng chữ từ ảnh, (2) AI model đọc dữ liệu roster theo từng loại file

1. Nhận dạng chữ từ ảnh (OCR) chỉ PaddleOCR, chưa qua parser/model: mỗi ô trong nhãn ảnh có được OCR đọc ra đúng chữ không

OCR Cần OCR server đang chạy
Bấm Chạy benchmark OCR để đo OCR đọc đúng bao nhiêu % ô (date, day, duty, dep, begin, end, arr) và bao nhiêu % ký tự.

2. Đọc dữ liệu roster theo loại file AI model đọc như ở /upload, so với nhãn

Loại file đang tải… Ảnh cần OCR server · toàn bộ khoảng 10–15 phút
Chọn loại file rồi bấm Chạy benchmark roster để đo AI model đọc đúng bao nhiêu % dòng so với nhãn, tách theo từng loại file.
