API Documentation

The public API of RosterParser, for other apps: read rosters, export calendars, look up airports and weather, compute night time.

OpenAPI JSON

Endpoints

Read a roster: image, PDF, CSV, Excel or TXTPOST /api/roster/upload Suggest a correctionPOST /api/roster/suggestions Roster rows to .icsPOST /api/calendar/export Read an ACARS picturePOST /api/acars/read Suggest a correction (ACARS)POST /api/acars/suggestions Routes of rosters on a world mapPOST /api/route-map Search airportsGET /api/airports One airportGET /api/airports/{code} Airport weather, 7 daysGET /api/airports/{code}/weather Night time of a flightPOST /api/night-time/calc
AuthenticationNone for now FormatJSON (UTF-8); uploads as multipart/form-data; times in ISO 8601 ErrorsHTTP status 4xx / 5xx with { "error": "message" }; send the cookie lang=vi for Vietnamese messages LimitsUploads up to 10 MB; one OCR queue for everyone (503 + busy: true = retry in a few seconds); weather cached 30 minutes

Uploaded rosters are only read, not kept; a roster stays on the server only when it is sent as a correction suggestion. The administration endpoints (labels, benchmarks, models, suggestions) are not part of the public API and will require an account. The reference below is in English; "Try it out" sends real requests to this server.
